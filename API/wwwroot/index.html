Vinilo Tico · API de Álbumes

Catálogo de álbumes de la tienda, disponible para el sitio web y la app móvil.

Endpoints disponibles

Método Ruta Qué hace Respuestas
GET /api/Album
/api/Album?artista=beatles		 Lista todos los álbumes. Con artista filtra por nombre del artista. 200
GET /api/Album/{Id} Consulta un álbum por su Id (Guid). 200, 404
POST /api/Album Crea un álbum nuevo con los datos del body en JSON. 201 con header Location
PUT /api/Album/{Id} Reemplaza los datos de un álbum existente. 204, 404
DELETE /api/Album/{Id} Elimina un álbum. 204, 404
Abrir Swagger Ver álbumes (JSON)
